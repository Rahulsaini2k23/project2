# Netflix Homepage Clone (HTML & CSS)

This is a "frontend clone of the Netflix homepage", built using only "HTML and CSS".  
The purpose of this project is to practice web development skills, especially layout and responsive design.

## 🧰 Features

- Netflix-style header and banner
- Background image section
- Simple CSS styling
- Static UI for learning HTML/CSS structure

## 🛠️ Technologies Used

- HTML5
- CSS3
